# Example Run Plan

[reproduce_seed2000.json](reproduce_seed2000.json) lists the seed-2000 jobs and
their dataset, checkpoint, profile, and output paths. Dataset files must be
prepared separately; the configuration is not a recorded experiment result.

See the [reproduction guide](../11_docs/reproduction.md) for commands,
the [dataset guide](../04_data/README.md) for inputs, and the
[output guide](../14_logs/README.md) for generated records.
