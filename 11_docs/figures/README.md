# Method Illustrations

These author-drawn illustrations accompany the method overview on the repository
homepage. SVG files preserve the original editable vector artwork. PNG files are
white-background browser renders for readable display in light and dark themes.

The homepage uses three white-background SVG slices of `motivation.svg`,
`motivation-gef.svg`, `motivation-tbf.svg`, and `motivation-rgr.svg`, so each
stage links to its own code index. The original artwork is unchanged.

| Illustration | Code explanation | Editable source |
| --- | --- | --- |
| Three filtering levels | [Shared search](../../01_LEAP/leap/common/README.md) | [motivation.svg](motivation.svg) |
| Probe distance fields | [Hausdorff](../../01_LEAP/leap/hausdorff/README.md) | [field_geometry.svg](field_geometry.svg) |
| Learning probe positions | [Learning and placement](../../01_LEAP/leap/training/README.md) | [probe_placement.svg](probe_placement.svg) |

The figures illustrate the method. They are not new benchmark measurements.
SDD uses point-set Hausdorff with nearest/farthest vertex fields, as described in
the [architecture guide](../architecture.md).
